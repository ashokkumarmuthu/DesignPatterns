## 🚀 How to Run

Launch the interactive CLI menu:
```bash
dotnet run --project DesignPatterns/DesignPatterns.csproj
```
Choose `1F`, `2F`, `3F`... to run any full real-world project example, or `ALL_FULL` to run all full project routines!
